## Security

No privileged API endpoint, browser tracking or raw error/recipient logging. Public checks use fixed targets, forbid redirects and have finite timeouts. Workflow permissions are read-only; it is skipped unless explicitly enabled. DB monitoring stays in the protected operator console. Backup encryption is not export automation: prepare a complete DB plus Storage snapshot separately, keep key custody separate, upload only encrypted data to the owner-approved destination, verify readback, and restore only on an isolated target. Do not read decrypted output before authentication completes. See the operations runbook for cleanup, plaintext handling, consistency and erasure requirements. SPF/DKIM values must come from the verified provider; preserve DMARC and existing mailbox records. Do not enable newsletters or Auth SMTP merely because transactional mail is configured.
