# T026 — Property profile editor

From the property status page, owners can edit information, business contacts and facilities. They can upload photos privately, preview uploads and select up to 12 for the proposed gallery. The first photo is the proposed cover. Each photo needs a short description for the public page. The editor shows a live five-part completeness score, read-only team information, and a link to the public profile for verified properties.

Assigned staff can upload and preview photos. Owners submit the full profile and ordered gallery for review. The current editor and photo controls require JavaScript.

## Files and migration

- `app/partner/properties/[id]/profile/page.tsx` loads the editor and photo library. The property status page links to it.
- `components/partner/property-profile-form.tsx`, `profile-photos.tsx` and `registration-photo.tsx` provide the form, completeness checklist, gallery controls, private preview and upload.
- `lib/partner/profile-editor.ts` and `profile-actions.ts` define and validate the form and submit review proposals.
- `supabase/migrations/20261105153416_t026_property_profile_editor.sql` extends the existing private verification proposal and adds owner-scoped read and submit functions. The migration is applied to free development Supabase, and `lib/database.types.ts` includes the generated signatures.
- `tests/database/property-editor.test.mjs`, `tests/e2e/property-editor.spec.ts` and the browser fixture cover the owner and staff paths.

## Review and security

All profile and gallery changes are private proposals. A pending initial registration keeps its single review request. Verified properties keep serving the approved fields and gallery during review. Requests with a decision asking for more information are locked in this editor pending the later review workflow. The Team section shows the current role and staff slot usage. Approval, publication and team invitations belong to later tasks.

The database checks current ownership, rejects stale changes and duplicate or cross-property gallery assets, and accepts repeated delivery of the same proposal. Staff cannot read or submit an owner proposal. Preview uses the existing membership-checked photo route and short-lived Storage URLs. Editing does not grant direct table or Storage writes.
