# T025 — Property switcher and portfolio overview

The partner home shows the All Properties Overview. The switcher lists owned and staff-assigned properties and opens the selected property’s status page. Owners see combined totals and a per-property breakdown for their unarchived properties. Staff assignments appear separately.

## Files and migration

- `app/partner/page.tsx` and `app/partner/properties/[id]/page.tsx` show the overview and selected property.
- `components/partner/property-switcher.tsx` and `components/partner/portfolio-overview.tsx` render the controls, totals and breakdown.
- `lib/partner/properties.ts` loads the current user’s memberships and portfolio totals.
- `supabase/migrations/20261105151322_t025_partner_overview.sql` adds a read-only aggregate function using existing tables and indexes. The migration is applied to free development Supabase. `lib/database.types.ts` includes the generated signature.
- `tests/database/partner-overview.test.mjs`, `tests/e2e/partner-overview.spec.ts` and the partner browser fixture cover the totals, switching and access boundaries.

## Metrics and security

Published offers count once from their first publication, including offers that have since ended. Active offers use the same current eligibility rules as public discovery. Activity compares the current Sri Lanka calendar month to date with the full previous month. The per-property cards show activity for the current month. Counts exclude events marked as bots, internal tests or rapid repeats.

The overview aggregates recorded offer views and WhatsApp and Call button clicks. Contact clicks are already collected. Offer view collection is pending, so recorded views can be zero even if a page has been visited.

The aggregate function binds the owner scope to the verified caller’s identity and returns counts without exposing individual events. The property page rechecks membership for every selected property. Partners can open their owned or assigned properties. Staff assignments are excluded from owner totals. Signed-out visitors are sent to sign-in, and unassigned property URLs return 404 for signed-in users.
