# T040 — Platform analytics, content health, and settings

Open the three pages from the admin overview.

- **Platform analytics** reports offer detail views, WhatsApp and call clicks, and the contact click rate over 7, 30, or 90 days in Sri Lanka time. It includes a daily chart with an accessible table and summarizes recorded view sources. Views without reliable attribution appear as Unknown. Contact clicks count attempts. The rate is unavailable when view collection is off, the endpoint is missing, or there are no views.
- **Content health** links to both pending review queues and lists live offers due to lose public visibility within 72 hours. The earliest of the publication deadline, end of the redemption date in Sri Lanka, and entitlement expiry determines the displayed end. An inactive property has been verified for at least 30 days, has no currently live offers, and has had no offer go live or receive a live revision during that period.
- **Settings** shows the deployment environment, site origin, reporting time zone, and configured view collection state. It is read-only because the build plan does not define editable settings.

## Files and migration

- `app/admin/analytics/page.tsx`, `app/admin/content-health/page.tsx`, and `app/admin/settings/page.tsx` implement the pages. `app/admin/page.tsx` links to them.
- `components/partner/property-analytics.tsx` shares the existing accessible daily chart with platform analytics.
- `supabase/migrations/20261106164530_t040_admin_insights.sql` adds two reporting functions and two indexes on non-excluded event timestamps. `lib/database.types.ts` includes the new functions.
- `tests/database/admin-insights.test.mjs` verifies aggregate accuracy, authorization, and listing eligibility. The admin browser spec and fixture cover navigation and phone widths.

## Security

Each page requires a verified platform administrator. The database analytics function uses the caller's row policies, while the private content health function checks administrator membership before reusing protected public eligibility functions. Anonymous callers lack execution permission. Analytics returns aggregate counts only. Settings reads an explicit set of non-secret fields. All pages inherit admin noindex metadata.
