## Mobile lab performance

Production mode, warm local server, empty browser context/cache per sample, mobile viewport/touch settings, requested 4x CPU slowdown and network profile of 150ms latency, 1.6Mbps download / 750Kbps upload. Values are medians of three navigation observations on the test host. Chrome/CDP localhost behavior and host CPU affect these measurements; they are a regression baseline, not a promise about real network latency or Render cold starts.

| Synthetic route  | LCP (ms) | Navigation-window CLS | Observed long-task blocking (ms) | TTFB (ms) | Transferred bytes |
| ---------------- | -------: | --------------------: | -------------------------------: | --------: | ----------------: |
| Home             |      576 |                     0 |                               55 |      13.7 |            189287 |
| Offer detail     |      536 |                     0 |                               44 |       8.7 |            186036 |
| Property profile |      528 |                     0 |                               43 |       7.1 |            181685 |

Gates: median LCP below 2500ms and navigation-window CLS at most 0.1. Measurements stop after navigation network-idle; later interactive layout shifts are outside this window. The long-task number is only the observed navigation blocking sum, not Lighthouse's TBT metric. INP and real-user 75th percentiles are not measured or claimed. Fixture images/catalogue and loopback API timings do not model live media, database load or a sleeping Free Render instance. [Web Vitals guidance](https://web.dev/articles/vitals), [Playwright emulation](https://playwright.dev/docs/emulation).
