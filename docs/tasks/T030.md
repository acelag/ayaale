# T030 — Starter active-offer limit

My Offers displays the selected property’s usage as “X of 3 active” across all offer pages. It shows how many slots are available, explains when verification or a subscription is required, and directs partners to pause or end an offer when capacity is full. Drafts are unlimited. Only approved offers that are live within their publication and redemption windows occupy slots.

## Files and migration

- `app/partner/properties/[id]/offers/page.tsx` displays property-wide usage alongside the paginated list.
- `lib/partner/manage-offers.ts` defines the usage result and `lib/partner/manage-offer-actions.ts` handles the full-capacity response on resume.
- `supabase/migrations/20261105174027_t030_active_offer_capacity.sql` adds the usage function and shares its slot count with the existing activation trigger. It updates the management function to identify a capacity rejection. No tables, columns or data backfill are needed. The migration is applied to free development.
- `lib/database.types.ts` contains the generated Supabase function signature.
- `tests/database/manage-offers.test.mjs`, `tests/e2e/manage-offers.spec.ts` and `tests/e2e/partner-fixture.mjs` cover the count and partner lifecycle.

## Security

The usage function requires a verified identity and current owner or staff membership for the property. It returns counts and publishing eligibility. The database locks the current subscription row before making an activation decision, so concurrent requests cannot claim the same last slot. Existing publication and entitlement checks still apply.
