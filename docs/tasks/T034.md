# T034 — Admin overview

Open `/admin` and sign in with an email-verified platform administrator account. The overview shows total counts and up to five entries each for pending property verifications, offer reviews, and unresolved reports. Verifications and offer reviews are oldest first. Reports show high priority first, then oldest first within each priority. The date labels use Sri Lanka time.

## Files and migration

- `app/admin/layout.tsx` and `app/admin/page.tsx` render the private overview, summary links, and queue previews.
- `app/partner/sign-in/page.tsx`, `components/partner/auth-form.tsx`, and `lib/partner/actions.ts` reuse the existing sign-in flow with a fixed admin destination.
- `supabase/migrations/20261106091246_t034_admin_overview.sql` adds the read-only `get_admin_overview` function over existing tables. `lib/database.types.ts` contains its API signature.
- `tests/database/authorization.test.mjs`, `tests/e2e/admin-overview.spec.ts`, and `tests/e2e/partner-fixture.mjs` cover the projection, role boundaries, and browser flow.

## Security

The database function verifies the caller’s current platform-admin assignment and uses the existing row-level security policies under the caller’s own session. Anonymous callers lack execute permission. Property owners and staff cannot read the overview unless they have a separate platform-admin assignment. The response carries only fields used by the preview. Verification evidence, applicant contacts, and reporter details remain outside the response. Admin pages are marked noindex.
