# T021 — Unavailable offer pages

Old links to previously published offers explain whether the offer is paused, ended or unavailable. The page suggests up to three current offers, with a link back to discovery even when there are no suggestions. Suggestions prioritize the same property, category and district in that order, then the newest publication. Withdrawn offers receive general suggestions.

## Files and migration

- `app/offers/[slug]/page.tsx` renders the old-link page and marks it noindex.
- `lib/offers/public-details.ts` loads the page state and the appropriate public fields.
- `supabase/migrations/20261105090559_t021_unavailable_offer_pages.sql` adds a read-only public RPC. It uses existing offer, property, revision and publication history tables. It is applied to free development Supabase.
- `lib/database.types.ts` records the generated RPC signature.
- `tests/database/discovery.test.mjs`, `tests/e2e/offer-details.spec.ts` and the browser fixture cover public eligibility, payloads and visitor navigation.

## Security and availability

The unavailable page can show a title from the last published revision. Archived or administratively hidden offers and offers from withdrawn properties use a generic page without the previous title. Unknown and never-published offers return 404. The unavailable response omits prior prices, terms, dates, cover references and contact details. Candidate offers use the same eligibility rules as discovery, including verified properties, current entitlement and open offer dates.
