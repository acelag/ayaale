# T045 — Dashboard notifications and urgent complaint alerts

The notification bell in the partner and admin headers shows the current user's unread count. It opens a private inbox with links to the relevant property, offer list, subscription, analytics, verification, or complaint case. Marking a notification as read updates the unread count. Repeating the action preserves the original read time.

A new property registration creates an acknowledgement for the applicant and a review notice for verified platform admins. Partners also see existing offer review, verification, complaint, and reminder notices they are still authorized to read.

When a moderator changes an unresolved complaint to high priority, the system queues one urgent alert per eligible platform administrator. The email worker prioritizes these over ordinary notices and suppresses an alert if the case is closed or downgraded before delivery. Previously high complaints are handled through the existing moderation queue.

## Files and migration

- `app/admin/notifications`, `app/partner/notifications`, and `components/notifications` provide the bell and private inbox pages. The admin and partner layouts render the bell.
- `lib/notifications`, `lib/partner/session.ts`, and `lib/database.types.ts` handle session reuse, inbox links, and the mark-read action.
- `supabase/migrations/20261106190345_t045_dashboard_notifications.sql` adds notification producers, inbox functions, an index for recent notifications, and urgent prioritization in the existing T043 email worker. The existing notification and delivery tables store the records.
- `tests/database/dashboard-notifications.test.mjs` and `tests/e2e/notifications.spec.ts` cover identity, unread counts, delivery priority, and desktop and mobile access.

## Security

Only the addressed recipient can read or mark an inbox item. Partner access is checked against current property membership. Admin notices require current platform administrator access. Alert bodies omit visitor evidence, reporter email addresses, and internal notes. The T043 worker rechecks eligibility before sending.
