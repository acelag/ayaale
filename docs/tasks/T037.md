# T037 — Offer reviews and revision history

Open **Offer review queue** from the admin overview. Pending and decided revisions have separate views. Open a revision to inspect the visitor-facing price, contact details, dates, terms, cover and gallery in a private preview. Revision history records each decision and reviewer message, and lets admins reopen earlier previews.

Approval requires the checklist for price, dates, inclusions, contact, photos, and terms. Requesting changes or rejecting a revision requires a message. An approved edit replaces the public revision when the decision commits. A rejected edit or request for changes leaves the existing approved revision in place.

An eligible offer with a current window goes live immediately. A future window is scheduled. If the property lacks an active entitlement or all three slots are occupied, the decision records approval and leaves the offer waiting to go live. Automatic activation is tracked in T041. Explicitly paused and ended offers keep their lifecycle state when an edit is approved.

## Files and migration

- `app/admin/offer-reviews` and `app/admin/page.tsx` provide the queue, private revision routes, history, and overview link.
- `components/admin/offer-review-*.tsx` and `lib/admin/offer-review*.ts` render the preview, checklist, and decision feedback. Photos reuse the protected, short-lived photo preview endpoint.
- `supabase/migrations/20261106103222_t037_offer_review.sql` adds the admin review and decision functions and an admin-only gallery read policy. It uses the existing offer, revision, and status history tables. `lib/database.types.ts` includes the new API signatures.
- `tests/database/manage-offers.test.mjs`, `tests/e2e/offer-review.spec.ts`, and the browser fixture cover access, preview, decisions, and publication behavior.

## Security

The database independently verifies current platform administrator membership and locks the property, offer, and submitted revision before saving a decision. A stale form or already-reviewed revision cannot overwrite a decision. Database checks confirm approval dates, verified property contact, and property-scoped photos. Existing entitlement and capacity enforcement still guards activation. The preview does not return private storage paths or publish the revision.
