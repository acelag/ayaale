# T017 — Discovery filters and sorting

The [local homepage](http://localhost:3000/#offers) has a filter sheet on phones and a centered filter dialog on wider screens. A sticky mobile toolbar exposes Filters and Sort. The sheet previews the matching offer count as the visitor edits criteria. Applied filters appear as removable chips. Reset keeps the current search, category and sort.

## Files and migration

- `components/discovery/filter-controls.tsx`, `lib/discovery/filters.ts` and `app/globals.css` implement the controls, validation and responsive layout.
- `app/page.tsx`, `app/api/discovery/route.ts`, `lib/discovery/feed.ts`, `lib/discovery/model.ts` and the discovery header, search, category and feed components carry criteria through navigation and pagination.
- `supabase/migrations/20261105080357_t017_discovery_filters.sql` adds the filtered discovery RPC and updates the T016 helper to share its query. `lib/database.types.ts` reflects the public RPC.
- `tests/database/discovery.test.mjs`, `tests/e2e/discovery.spec.ts` and the loopback discovery fixture cover filtering, sort order, count previews and pagination.

The migration is applied to free development Supabase. It retains the original RPC signature and response shape for T016 callers.

## Behavior and security

Destination searches district names case-insensitively. Price bounds are inclusive and use the advertised LKR amount. Selected dates must fit within the redemption window. A single date is treated as a one-day window. Category views offer an adult count, and Stays adds exact nights.

Newest First keeps fair property alternation. Lowest Price compares the displayed amounts across pricing units. Biggest Discount uses the approved discount percentage and places offers without discounts last. Ending Soon uses the publication deadline. Publication time and UUID break ties in the other sorts.

The database validates the criteria and rechecks T016 eligibility before counting and paging. The count covers all eligible matches within the publication cutoff. Each page returns at most 12 cards. Continuations bind to the criteria and sorting order. Exact counts evaluate the full matching set, so query cost depends on the active catalog size.

The public read uses the publishable key and a fixed, read-only projection. Anonymous access to raw offers remains denied, and the projected fields exclude private revision data. A modal dialog keeps background controls inert, closes on Escape and returns focus to its opener.
