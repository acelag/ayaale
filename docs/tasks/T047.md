# T047 — Admin newsletter editor

Open Marketing → Newsletters in the admin overview. Create a draft, edit the subject and introduction, search for live offers by title or property, and select up to six. Offer cards fill from the current approved revision. Move buttons set the order. Mobile and desktop previews update as the draft changes.

An incomplete draft can be saved. A test email uses a saved draft with five or six current offers from at least two categories. If an offer expires or its approved revision changes, remove the old selection and add a current offer. Test mail uses the same text and HTML as the preview, with a test label, and goes only to the signed-in admin’s verified email. The saved draft remains a draft.

## Files and migration

- `app/admin/newsletters` and `components/newsletter/newsletter-editor.tsx` provide the list, editor, picker, and preview.
- `lib/newsletter/editor.ts` renders the text and HTML. `lib/newsletter/editor-actions.ts` and `editor-config.ts` implement saves, search, and test mail.
- `supabase/migrations/20261106192046_t047_newsletter_editor.sql` adds restricted draft operations and a private test-send log. Drafts and selections use the existing campaign tables. `lib/database.types.ts` records the API signatures.
- `tests/database/newsletter-editor.test.mjs` and `tests/e2e/newsletter-editor.spec.ts` verify persistence, access, eligibility, order, and preview behavior.

## Security

The database checks current platform admin access for every operation. Draft saves use the saved version to prevent overwriting someone else’s edit. The preview escapes all copy and runs in a sandboxed iframe. Test send accepts no recipient field. It checks eligibility again, limits each admin to five tests per hour, and uses a one-use request and provider idempotency key. Only the service role can record provider acceptance.

```sh
AYAALE_TEST_DATABASE_URL=postgresql://postgres@127.0.0.1:54329/ayaale_test npm run check:all
git diff --check
```

To enable test mail in an authorized HTTPS deployment, set `NEWSLETTER_TEST_SEND_ENABLED=true` with `TRANSACTIONAL_EMAIL_FROM`, `RESEND_API_KEY`, and `SUPABASE_SECRET_KEY` on the web service. The verified sender setup is shared with T043. The test function cannot send to subscribers. [Resend Send Email](https://resend.com/docs/api-reference/emails/send-email)
