# T003 — Next.js application initialization

## Scope and files

Next.js App Router with strict TypeScript; Tailwind v4 through PostCSS; shadcn/ui configuration and Button primitive with Ayaale token styling. The server-rendered homepage is a small foundation placeholder, not the T015 discovery experience.

Created package.json/package-lock.json, tsconfig.json, next-env.d.ts, next.config.ts, postcss.config.mjs, components.json, app/layout.tsx, app/page.tsx, app/globals.css, components/ui/button.tsx, lib/utils.ts and .nvmrc. Updated README and task board. The CSS imports the T002 token source and maps semantic color variables into Tailwind utilities. No auth, Supabase client, forms, offers, infrastructure or CI added.

## Schema and migrations

None. T004 provisions environments; T007 begins schema work. Supabase credentials are not required to run this placeholder.

## Commands

```sh
npm ci
npm run dev
# Production verification, stop development first if necessary:
npm run build
npm run start
# Standalone verification without introducing the T005 test harness:
npx tsc --noEmit
npm run check:contrast
git diff --check
```

Use a supported Node runtime matching .nvmrc (Node 24 LTS). Installed dependency versions are pinned in package.json and the lockfile. Development binds to loopback; production start uses Next.js defaults and Render's PORT environment when configured in T004.

## Security and SEO considerations

No secrets in source or browser bundles, no service-role use, no remote font requests, no database connection and no mock booking/payment endpoints. Environment files remain ignored. The placeholder has metadata, language, semantic landmarks and a noindex directive to avoid publishing unfinished content to search. Canonicals, sitemap and launch indexing remain in T050. The Next.js identification header is disabled. Do not expose the dev server publicly or claim that this scaffold implements authentication/RLS. Deployment hardening and secrets belong to T004 and later security tasks.

## Acceptance criteria

- Production compilation and strict TypeScript checks pass.
- App Router serves a server-rendered homepage with one H1, main landmark and keyboard skip link.
- Tailwind and shadcn Button render with the T002 semantic tokens and minimum 44px targets.
- Homepage uses responsive gutters, wrapping text and constrained reading width.
- No inaccessible fake search, signup, booking or checkout controls.
- No future-task features or schema changes.
