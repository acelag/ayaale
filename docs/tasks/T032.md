# T032 — Subscription and billing

A verified owner can open **Subscription and billing** from a property’s status page. The screen shows the Starter trial state and dates in Sri Lanka time, effective live offer usage, future Starter pricing, and an empty billing history. The property switcher lists the owner’s properties and keeps them on the subscription screen.

## Files and migration

- `app/partner/properties/[id]/subscription/page.tsx` renders trial status, usage, pricing, and billing history.
- `app/partner/properties/[id]/page.tsx`, `app/partner/page.tsx`, and `components/partner/property-switcher.tsx` add the owner link and property switching.
- `supabase/migrations/20261106064124_t032_subscription_status.sql` adds an owner-only read function. It reuses the existing catalogue, trial periods, and T030 usage calculation. Existing tables and trial records require no backfill. `lib/database.types.ts` includes the Supabase function signature.
- `tests/database/subscriptions.test.mjs`, `tests/e2e/subscription.spec.ts`, and `tests/e2e/partner-fixture.mjs` cover trial state, access, and desktop and mobile behavior.

## Security and billing behavior

The server checks ownership before rendering. The database independently checks the authenticated identity’s current owner assignment and excludes archived properties. The query returns display fields and prices. Raw billing records and private ledger identifiers stay out of the response.

Trial expiry is calculated at read time so the display follows the existing entitlement rules even before a background job updates the stored state. The dates shown use the original trial period. The billing section is informational, and payments remain unavailable.
