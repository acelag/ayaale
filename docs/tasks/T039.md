# T039 — Starter launch trial allocation

The admin overview shows how many of the 100 Starter launch trials have been allocated and how many remain. When all places are allocated, admins can still approve verified properties.

Registration reserves no place. The existing T009 allocator locks the campaign row during first approval and commits the property approval, allocation record and six-month Starter subscription together. The permanent ledger allows one launch allocation per property. Transfers, subsequent verification and trial expiry leave the original allocation in the count.

## Files and migration

- `app/admin/page.tsx` displays the admin counter and the campaign-full state.
- `supabase/migrations/20261106163519_t039_trial_allocation_counter.sql` extends the existing overview query to read the campaign count under its current admin-only row policy. The migration uses the existing campaign and allocation tables.
- `tests/database/subscriptions.test.mjs` exercises competing approvals through the registration and admin verification functions. The existing admin overview browser test and fixture check the counter on desktop and mobile.

## Security

The database verifies platform administrator membership before returning the overview. The counter exposes aggregate totals only. Existing database locks and constraints protect the final slot and prevent the campaign count from diverging from the ledger.
