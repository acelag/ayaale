# T019 — Offer contact actions and click tracking

Offer details display WhatsApp and Call when the property has a valid public number for that channel. The buttons sit in a bottom bar on phones and in the price panel on wider screens. The mobile layout reserves space for the bar and the device safe area. WhatsApp opens a draft with the offer title and its absolute URL. Copy Link uses the clipboard and offers a selectable link if clipboard access fails.

## Files and migration

- `components/offers/contact-actions.tsx` renders the controls, clipboard feedback and best-effort click requests.
- `app/offers/[slug]/page.tsx`, `lib/offers/public-details.ts` and `app/globals.css` connect the public numbers, build the links and style the mobile bar.
- `app/api/offers/[slug]/contact/route.ts` validates click requests and calls the service-only RPC.
- `supabase/migrations/20261105085011_t019_offer_contact_clicks.sql` extends the detail projection with public phone and WhatsApp fields, adds contact rate limits and writes events to the existing private contact-click table. The migration is applied to free development Supabase.
- Generated database types, database tests and browser fixtures cover the new contract.

## Security and event semantics

The links use validated E.164 numbers and the configured site URL. Tracking accepts POST requests from that site's origin and validates the slug, channel and event UUID. The database rechecks that the offer is active and has the requested public channel. The write RPC requires a server-only credential.

The client suppresses repeat tracking for the same channel for three seconds per mounted page. The database deduplicates retried event UUIDs for an offer and channel. It caps new click attempts at 120 per offer and 600 globally per minute. Each event records link activation with an unknown attribution source, an offer reference, a channel, a hashed event key and a timestamp. The request carries no message contents, customer identity or phone number. Copy Link leaves the contact event count untouched.

The contact links use native navigation and tracking runs separately. Browser and database fixtures use synthetic numbers and a loopback WhatsApp response.
