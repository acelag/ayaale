## Schema and security

Thirteen private tables cover reports/manual moderation, view/contact events/daily aggregates, subscribers/append-only consents/digested tokens, campaigns/selections/deliveries, notifications and retryable email logs. RLS and explicit ACLs deny all browser access; sensitive details never enter public types. Invoker functions use fixed empty search paths. Same-target references, exact consent evidence, Friday/mixed-offer readiness and send uniqueness are constrained. Storage fields do not enable a collector, sending workflow or provider integration. See the [schema guide](../database/T010_REPORTING_COMMUNICATIONS.md) for full guarantees, operational contracts and limitations.
