# T023 — Basic PWA installation

Ayaale has a stable web app identity and opens the public home page in standalone mode when installed. The icon adapts the site's compass motif and green palette. Its artwork fits inside the mask-safe area for Android launchers.

## Files and schema

- `app/manifest.webmanifest` declares the app name, scope, launch URL, standalone display and install icons.
- `app/icon.svg` is the browser icon and the artwork source for the PNG files.
- `public/icons/ayaale-192.png` and `public/icons/ayaale-512.png` serve regular and maskable icons. `app/apple-icon.png` provides the 180 px Apple touch icon.
- `app/layout.tsx` uses the existing page background as the browser theme color.
- `tests/e2e/pwa.spec.ts` checks Chromium installability, asset responses, icon dimensions and the public launch URL.

The change uses static assets and requires no database migration.

## Security and browser behavior

The manifest, icons and launch URL are same-origin. Install from the browser menu using a trusted HTTPS deployment for real phones. The local browser tests use a trusted loopback origin. Ayaale requires an internet connection and uses normal browser and server caching. There is no service worker or notification permission request. [Chromium installability guidance](https://developer.chrome.com/blog/update-install-criteria)
