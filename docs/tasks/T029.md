# T029 — My Offers and offer lifecycle actions

Owners and assigned staff can open My Offers from a property’s status page. The list shows drafts, offer states, review status and messages, and publication and redemption deadlines. Ended and expired offers remain listed with recorded activity. The list shows 20 entries per page.

Partners can pause an active offer, resume a paused offer when it is still eligible, and confirm before ending an offer. A duplicate starts a separate private draft from the approved revision when one exists, or the latest revision or source draft otherwise. Publication and redemption dates are cleared so the new offer gets fresh dates.

Edit for review opens one private draft for the current offer. Submission adds a separate review revision. The approved offer and its existing publication state remain in place during review. Changes-requested offers can be revised and resubmitted. The lifecycle controls require JavaScript.

## Files and migration

- `app/partner/properties/[id]/offers/page.tsx` renders the paginated list. The property status page and wizard link to it.
- `components/partner/manage-offer-button.tsx`, `lib/partner/manage-offers.ts`, and `lib/partner/manage-offer-actions.ts` implement the controls, status labels, confirmation and feedback.
- `supabase/migrations/20261105173349_t029_manage_offers.sql` is applied to free development Supabase. It adds the draft-to-revision link and property-scoped list and lifecycle functions. It extends the existing wizard submission function to append a review revision to an existing offer. `lib/database.types.ts` records the generated signatures.
- `tests/database/manage-offers.test.mjs`, `tests/e2e/manage-offers.spec.ts` and the partner browser fixture cover the lifecycle paths.

## Security and behavior

Each read and write checks current property membership. Lifecycle mutations check the last-read offer version and use the existing publication, entitlement and capacity guards. Edited submissions validate their base revision and preserve the approved pointer. One open edit draft and one pending review revision are allowed per offer. Public discovery and old offer links recheck eligibility on the next request.

Historical counters summarize recorded activity. Contact clicks are collected. Offer views depend on view collection, which remains pending. Complete hosted flows still need a real property with approved offers.
