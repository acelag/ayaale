## Commands

With Node 24.22.1 selected:

```sh
npm ci --include=dev
npx playwright install chromium
npm run check
npm run test:e2e
# Or run both groups together:
npm run check:all
```

Use npm run format for intentional formatting edits and npm run lint:fix for available lint repairs. Review the diff afterward. See [testing guide](../TESTING.md) for individual commands and failure investigation. Browser tests build the production app, use isolated port 3100, and refuse to reuse an existing server.

## Security and cost considerations

Pinned dependencies and upstream action commit SHAs, read-only contents permission, non-persistent checkout credentials, normal pull_request events, no project secrets, no deployment commands, a bounded timeout and branch concurrency cancellation. Failure artifacts expire after three days. Browser fixtures do not connect to Supabase; its public variables are explicitly empty for the test server. Keep future test data synthetic because traces/screenshots can contain rendered content. Generated reports remain ignored locally.

Production-dependency npm audit reports zero vulnerabilities. The full development-tool tree reports 16 moderate entries propagated from the minimatch glob-amplification advisory GHSA-g3hv-75wg-m249. No high/critical issues were reported. The affected legacy dependency ranges do not have a safe drop-in fix in this toolchain; npm's suggested forced downgrades would break the modern setup, and overriding every minimatch consumer to a new major would change its API. This finding is documented, not hidden or labelled fixed. Keep lint patterns/configuration trusted and revisit upstream compatible fixes. It does not affect the production dependency tree.

No paid hosting, larger CI runners or billing changes were enabled. The workflow is prepared for the confirmed public repository using standard GitHub-hosted Ubuntu. Hosted activation still requires publishing the source/workflow; no hosted run or branch protection is claimed.
